Before you start

A few honest answers.

Can I try it without an API key?

Yes. The practice workflow uses synthetic drawings and scripted answers. It exercises scoring, failure investigation and report export without making a model call.

Can I use my own inspection photos?

Yes, through the local labeler and import command. A person supplies the labels. Browser photo uploads and project creation are not implemented. The guide explains the workflow.

Is the model choosing every test?

Practice checks use deterministic rules. An optional Muse Spark planner can select tests in an explicitly enabled live run. Saved examples record which planner actually ran. A scripted workflow is not proof of live agent intelligence.

Does a passing result certify a model as safe?

No. GO_CANDIDATE means the recorded evidence met the configured policy. It is not deployment approval or safety certification. A person must review every release decision.
