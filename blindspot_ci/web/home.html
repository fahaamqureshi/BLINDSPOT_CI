How one test works

An agent chooses

Muse Spark 1.3 reads the list of tests with the labels hidden. It calls choose_next_test or finish_testing. The server rejects any other call.

The model segments

SAM 3.1 gets the photo and a word such as "fire hydrant". It returns boxes and masks.

Python scores

Code compares the best box with the box a person drew. No model grades itself.

You get a report

Pass counts with uncertainty, every failure with its photo, a release gate decision and an evaluation card you can download.

Three more Meta models help around the edges: Muse Image makes labeled dark and blurry variants, Muse Voice Transcribe turns a spoken reviewer note into text, and Muse Wonder writes a plain-language audit. None of them can change a score.

What the release gate decides

After a run is saved, the release gate reads it and gives one decision with the reasons and the next experiments to run. It needs no key and costs nothing. Human review is mandatory for every decision.

DEMO_ONLY
Mock, synthetic or generated evidence. It can show nothing else.
NO_GO
A required condition is below the 0.90 bar on enough scored cases. The saved COCO live run gives this: low light passed 6 of 10 and small object passed 19 of 24.
NEEDS_REVIEW
Nothing is clearly failing, but the evidence is thin, uncertain, unreviewed or not live.
GO_CANDIDATE
Every check passed. It is not an approval and not a safety certification. A person still decides.
