# Decisions

This file records the design decisions that the code already makes, with the file that enforces each one. It is a record for reviewers, not a proposal. Where a decision has a known cost, the cost is stated. New decisions should be added here in the same shape: decision, where it is enforced, why, and what it costs.

## Decision list

| Number | Decision | Enforced in | Why | Cost or limit |
| --- | --- | --- | --- | --- |
| D1 | Plain Python is the only judge. No model grades anything. | `blindspot_ci/experiment/scoring.py`, `blindspot_ci/evaluator.py` | A model grading itself hides its own blind spots. Deterministic scoring can be re-run and checked. | Box overlap only for photos. Mask quality needs a separate offline step. |
| D2 | Labels come from a person, never from a model, and stay hidden until scoring. | `blindspot_ci/experiment/cases.py` (`public_case`), `blindspot_ci/experiment/planners.py` (prompt text) | The test is only fair if the planner and the model cannot see the answer sheet. | Label quality depends on one person until a second annotator exists. |
| D3 | One IoU bar for a single case: 0.35 by default, set by an environment variable. | `scoring.py` default, `blindspot_ci/config.py` min IoU setting | A single stated bar keeps runs comparable. The offline sweep shows how results move at other bars. | Any single bar is a choice. The sweep in `docs/EVALUATION_PROTOCOL.md` is the remedy, not a second hidden bar. |
| D4 | Six statuses, and UNKNOWN and ERROR are never scored. | `scoring.py` `score_case` | A case a person cannot judge, or a call that failed, must not count as a model miss or a pass. | The gate penalizes a high unscored share instead of ignoring it. |
| D5 | Absent means absent: no detection passes, any detection fails as a false positive. | `scoring.py` absent branch | False alarms are a real failure mode and need their own count. | Open dataset absent labels depend on annotator verification; COCO absent means no annotation of that class, which is weaker. |
| D6 | Counts with Wilson intervals, never a bare percentage. Slices under 5 scored cases are underpowered. | `scoring.py` Wilson interval and minimum slice size, `blindspot_ci/experiment/slice_tests.py` | Small samples mislead. The interval states the uncertainty in the same number a reader quotes. | Intervals still treat photos as independent; video frames need the clip-aware interval. |
| D7 | Clip-aware intervals for video: bootstrap whole clips or tracks, fixed seed. | `blindspot_ci/experiment/cluster_ci.py` | Frames from one clip look alike, so counting frames overstates certainty. | Needs at least 5 groups with repeats before the gate uses it; otherwise it reports not available. |
| D8 | The gate has four decisions and fixed exit codes. Mock, fixture, synthetic, generated and corrupted evidence can only give DEMO_ONLY. | `blindspot_ci/experiment/release_gate.py` | A release tool must refuse to dress practice answers as proof. Exit codes let a pipeline act without parsing prose. | Good-looking generated results still cannot advance a release. That is deliberate. |
| D9 | GO_CANDIDATE needs live evidence, enough cases per required condition, a second annotator with kappa at least 0.60, and no training overlap. | `release_gate.py` default policy | Each check blocks a known way that weak evidence looks strong. | GO_CANDIDATE has never been reached. It stays unreachable until own photos and a second labeler exist. |
| D10 | Training overlap table is explicit and UNVERIFIED. | `release_gate.py` overlap table, `docs/release-gate.md` | A test the model may have memorized proves little. The table forces the question into every gate run. | DAVIS is marked likely seen and COCO unknown from paper summaries. The owner must check the SAM papers before quoting either. |
| D11 | Budget is reserved before every paid call. One server-wide guard covers image, voice, audit and experiment spend. | `blindspot_ci/budget.py`, `blindspot_ci/api.py` session guard, `blindspot_ci/providers/sam_video.py` reserve step | A click loop or a retry storm must not spend without limit. Reserving first makes the worst case the cap. | Estimates are list-price guesses. The provider bill is the truth and can differ. |
| D12 | Cache by input hash, and replaying a saved answer keeps an honest CACHE label. | `blindspot_ci/cache.py`, `blindspot_ci/experiment/runner.py` source label and run mode | Re-scoring must be free and must never pretend a replay was a fresh live call. | The live cache key has no prompt version, so a format change needs a manual cache clear. |
| D13 | Every run is saved as one JSON file with image hashes, latency, source label, cost and planner reason. | `runner.py` save step, `blindspot_ci/provenance.py` | A result that cannot be re-read for free cannot be checked. Hashes catch a photo changed after labeling. | Run files and the cache grow without limit; cleanup is manual. |
| D14 | The Muse planner may only pick an untested case through one validated tool call, or stop. Anything else stops the run. | `experiment/planners.py` Muse planner | An agent that can invent a case or grade a result breaks the whole design. Narrow tools keep it a test picker only. | A reply with no tool call ends the run early. The scripted planner remains the headline order until the agent proves itself. |
| D15 | Generated variants inherit the source box and are labeled GENERATED, never mixed into real evidence. Measured corruptions keep labels exact because pixels never move. | `blindspot_ci/experiment/stress.py`, `blindspot_ci/experiment/corruptions.py` | A generative edit can move the object, so its box is an assumption. A measured corruption cannot, so its label stays a measurement. | A person must still confirm each generated box by eye. Corruptions test robustness, not real-world frequency. |
| D16 | Voice and Wonder are helpers that never change a score. Their input text is treated as untrusted. | `blindspot_ci/providers/meta_extras.py`, `blindspot_ci/api.py` notes, voice and audit routes | Notes and audits help a person review. Letting them move a number would break D1. | Wonder can still write a wrong sentence. A person reads it beside the scores. |
| D17 | Local-first security: loopback host guard, same-origin posts, and no public bind while live mode is on. No sign-in. | `blindspot_ci/security.py`, `blindspot_ci/cli.py` serve step | The tool holds a paid key on a personal machine. The guard stops a stray web page from spending it. | No public live deployment is safe without adding sign-in first. Public use stays mock-only. |
| D18 | Long video uses box prompts, one paid streaming call per sequence, no retries, and raw text saved before parsing. | `providers/sam_video.py`, `blindspot_ci/experiment/temporal.py` | A retried video call doubles the cost. Saved raw text lets a scoring fix be applied for free, which already happened once. | A truncated stream marks later frames as errors. One sequence is weak evidence and is reported as such. |
| D19 | The smaller-box fix: scale returned boxes by each box frame size before IoU. | `docs/long-video-test.md`, temporal scoring | The service returned boxes at 586 by 440 for a 1173 by 880 clip. Comparing raw numbers gave a false 0 of 16. | Human MOT20 boxes include hidden body parts, so occluded scores still mix a labeling convention with model error. |
| D20 | Docs use plain wording with a checked style gate, and mock results are always labeled as mock. | `scripts/check.py` docs style scan, source labels in `runner.py` | A reader who cannot tell practice from proof will quote the wrong number. The gate makes the wording rule mechanical. | The style rule bans asterisks in docs prose, so docs use plain headings and hyphen lists. |

## Decisions not yet taken

- Whether the Muse planner becomes the default order: blocked on the compare-agent evidence in gap P1. Default stays scripted until then.
- Public hosting account and hostname: owner action in `docs/free-deployment.md`. No agent should create the account or set a key on a public service.
